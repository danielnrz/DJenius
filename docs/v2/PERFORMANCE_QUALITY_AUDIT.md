# V2 Performance Quality Audit

## Status and acceptance boundary

This audit traces the production `TransitionCandidate -> PerformanceRecipe ->
PerformanceTransition -> renderer -> audio` path. It was started after the
second human listening verdict found that V2 still did not feel like an active,
practiced DJ. Automated distance measurements below are diagnostic only. The
human DJ-quality gate remains open until the recovery checkpoint is heard.

The controlled real-audio lab is private at
`/tmp/djenius_performance_lab/`. It uses one anonymous compatible track pair,
fixed source/target anchors, a four-bar transition, real cached stems, and a
plain-crossfade reference. Its manifest records the compiled action schedule,
actual compiler operations, renderer family, and aligned difference metrics.

## Root causes confirmed and corrected

1. Adjacent handoffs previously optimized a middle track independently. Set
   Director now carries a typed `TrackAppearance` through every beam state and
   passes a path-dependent `SourceAppearanceConstraint` into Candidate
   Composer. Candidate bars/anchors that would begin before the protected
   establishment window are infeasible upstream. The renderer shift remains
   only as backward compatibility for legacy/manually assembled plans.
2. Phrase cut used a tiny target seam but consumed a full multi-bar target
   overlap in preview/full-set cursor bookkeeping. Both render paths and Set
   Director's exact duration equation now use the actual seam advance.
3. Stem handoff could audition with supplied stems, but the real application
   full-set path never loaded them and the full renderer rejected all stem
   candidates. Both boundaries now carry and validate segment-local stems.
4. `riser_impact` and `loop_shortening` preserved typed operations but executed
   over ordinary crossfade envelopes. Phase-5 recipes now compile an explicit
   mix-choreography directive that the renderer executes as a build and phrase
   landing.
5. EQ blend and drum bridge shared a generic fade. Phase-5 EQ now stages upper
   frequencies before a bounded bass swap; drum bridge adds a deliberate
   arrangement pocket plus its generated groove.
6. Echo out mixed a decaying copy across a conventional fade. It now captures
   the outgoing beat post-fader, exits the dry source, and clears space for the
   target landing.
7. Audition's generic spectral-continuity/HF penalties treated intentional
   transformation as damage. It now applies small, family-specific allowances
   for expected frequency movement while continuing to penalize bass collision,
   mud, spectral holes, and excess beyond those bounds. This is damage-model
   correction, not a creative score bonus.

## Real recovery checkpoint

The latest private 600-second-target plan rendered 661.228 seconds exactly as
estimated (sample-level plan/render agreement), using five anonymous tracks and
`echo_out -> loop_shortening -> drum_bridge -> riser_impact`. All four new-plan
anchor shifts were `0.0`. Middle tracks received 33.599, 130.888, and 191.989
seconds of independent airtime after their entry consumption point, exceeding
their protected establishment envelopes.

The review package is `/tmp/djenius_performance_lab/listening_checkpoint/`.
It contains stable links to the original V1, previous V2, and recovery V2 full
renders; fixed-anchor controlled family comparisons; and one contextual clip
for each selected recovery handoff. Human acceptance is deliberately marked
`pending` in its manifest.

## Remaining honest limitations

- Human-audible quality and taste are not proven by this audit. The third human
  listen is the acceptance gate.
- Bass swap is correctly structured but is still subtle in full-band distance
  on the controlled pair; low-end ownership should be judged on monitors or
  headphones before further change.
- Drum bridge is structurally more than EQ blend, but its direct foundation
  comparison remains relatively close; the contextual clip should determine
  whether the percussion reads as a bridge rather than background decoration.
- Reverb wash is renderer-reachable but is not a Phase-5 family. It should not
  be counted as generated, auditioned, or selected Set Director behavior.
- Track appearances now guarantee entry/establishment/exit coherence, but
  featured-section and energy-purpose fields are an initial typed planning
  layer, not yet a full section-story optimizer across an entire set.
